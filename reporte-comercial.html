Exportar estado completo

Descarga un archivo JSON con todas tus maestras y ventas acumuladas. Importante: exportá después de cualquier cambio grande. Podés usar este archivo para mover el estado a otra máquina o para restaurar ante cualquier imprevisto.

Importar estado

Reemplaza todo el estado actual con el contenido del archivo JSON seleccionado. Se recomienda exportar el estado actual antes de importar.

Restaurar a datos iniciales

Vuelve todo al estado original (abril 2026 con las 59 zonas iniciales). Se perderán los cambios y ventas agregadas.

Exportar reportes gerenciales por sucursal

Descarga un archivo HTML por cada sucursal activa, con sus datos filtrados embebidos. Cada archivo es independiente: el gerente lo abre directo en su navegador y solo ve los datos de su sucursal. Las sucursales cerradas (Mendoza, San Cristóbal, Morón) no se incluyen.

Los archivos generados no permiten cargar nuevos datos ni cambiar la sucursal: son de solo lectura. Cada vez que cargues nuevas ventas en este dashboard, regenerá los archivos y reenvialos a los gerentes.

Exportar reportes por líder

Descarga un archivo HTML por cada líder (comerciales y de redes), con sus datos filtrados embebidos. Cada archivo es independiente y muestra solo las operaciones de los vendedores del equipo del líder. Los archivos quedan auto-filtrados por el líder; no se permite cambiar el filtro.

Igual que los reportes gerenciales pero a nivel equipo: pensados para mandar a cada líder. Son solo lectura.

Exportar informe completo para Directorio

Descarga un único archivo HTML con todos los datos (todas las sucursales activas), pero sin el botón de Gestión de Datos. Pensado para enviar al directorio: pueden navegar, filtrar y explorar libremente, pero no pueden cargar ni modificar información.
